## 4. 数值存疑点（**属于口径/设计，不是 bug**；需要建模手拍板）

1. **L0 双计数偏差**：实测 +1.6%（i）/+3.5%（ii），文档预期 +22.5%。
   原因：$\rho^{\text{storm}}$ 用宽滩潜在后退，实际被窄滩因子（0.55–0.71）和干滩耗尽压低。
   **影响论文措辞**，不影响 D11 的“>30% 才切换”规则。是否改 $\lambda_s/\Delta y$ 或改措辞 → 建模手。
2. **E3 方向**：spread 的 $E_w$ 最大（24 766），不是文档预期的 early（21 902）。
   原因：早期风暴打在宽滩上（$f<1$）；late 的保护年数最好但 2042 残余滩宽最差（0.7 m）。
   若建模手认为“early 必须最大”，需要改事件强度/时距设计并重跑 E3。
3. **热点峰值 3.04 m/yr 低于 DEQ 3.8–4.0 下沿**：模型可能**低估**建筑风险（方向与旧文档“偏保守”相反）。
   若要贴合 DEQ，需要上调 $a_h$ 或 $\rho_e$ → 全套重跑。
4. **$c_0$ 无交叉点**：`marginal_plus_fixed` 下 $c_0\in[0,10]$M 对 $E_b/E_w$ 无影响（沙源先绑定），
   与“不要预设翻转点”一致；若论文必须有交叉点，需要改 $C_{\max}/S_{\text{borrow}}/c_1$ → E4 重跑。
5. **指标定义域**：所有时长/暴露只在**中央 5 km**；若论文改全域 9 km → 全套重跑。
6. **$T_{\text{first,fail}}$ 的 f 线性插值**：把穿越时间从步长量化里解放出来；若改回“首个 $\ge$ 阈值的步边界”，
   四个时长指标会小幅变化 → 全套重跑（动力学不变，只重算指标）。
7. **S1 的 `rho_e_scale` = 0.6498**，文档写 0.649（舍入）——无需重跑。
8. **场均值 2.31 与 DEQ 段平均 1.7** 是两回事（热点参数化抬高了走廊均值）；
   若要求“场均值=1.7”，等于改 $a_h$ → 全套重跑。
9. **`targeted` 只发生 1 个项目**：本地沙 2.45M 被首个项目吃满，“可追加至 4 次”在当前约束下不会发生；
   若要求多次，需改每次方量上限 → E4 重跑。
10. **Sobol 第 3 组共线**：$V=\min(V_{15},S_{\text{borrow}},V_{\text{event}},\text{budget})$，
     $V_{15}$ 的 $S_1=0$、另两个接近/超过 1；只能读排序，不能读份额 → 提高 N 或换输出。

## 5. 重跑时的固定纪律（避免“重跑后不可比”）

1. **种子不变**：MC 的 `seed_i=(seed*1000003+i) mod 2^32`；事件表按 `scenario+seed` 预生成并共享。
2. **先跑 L0/E0，再跑 E1–E7**；任何口径改动都要在 `results/SUMMARY.md` 顶部记录“本版口径”。
3. **每次重跑后**：`python -m exp.check_all`，并把 `results/validation/pytest.log` 与 `AUDIT.json` 一起提交。
4. **不要手改 `results.json`**；所有数字必须由代码生成。
5. 提交信息格式：`[code] R<n> <改了什么>；<影响范围>；check_all PASS`。
