## 2. 目录是不是必须的？——**不是**

我把题目 PDF 又扫了一遍：

```
"table of contents" 出现 0 次
"contents"          出现 0 次
```

题目只要求：**1 页摘要 + 1 页技术信 + ≤25 页报告**（+ 物理假设、参数与单位、数值/解析结果、验证、不确定性、可执行建议）。**没有要求目录。**

所以目录是"锦上添花"，不能为它牺牲 25 页红线。

## 3. 两条改法（都能回到 25 页，选一条）

### 方案 A（推荐，零风险）：删掉目录

回到 v4 的 25 页结构（24 页正文 + 1 页 AI 报告）。
- 优点：5 分钟，不碰正文；
- 缺点：少一个"看起来正式"的加分项（但评委不会因为没目录扣分）。

### 方案 B（保留目录，但要压成半页）：目录只列一级标题、且不另起页

现在目录占满一整页（30 条，含二级标题）。改成：

```latex
% 只列到一级标题：10 条，约 1/3 页
\setcounter{tocdepth}{1}
\tableofcontents
% ⚠ 不要在目录后加 \clearpage / \newpage，让 §1 紧接在同一页
\section{Introduction}
```

这样目录 ≈ 1/3 页，§1 从同一页开始，**总页数回到 25**。

> 如果压完还是 25 页放不下（因为正文段落被挤动），就退回方案 A。
