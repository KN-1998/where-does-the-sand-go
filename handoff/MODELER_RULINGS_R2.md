## 2. 第 9 条的裁决（唯一需要拍板的）

**现状**：合同 §4.1 是 **pick-then-veto**——先取"单位成本减险最大"的候选，再判它自己的 $T_{10}$ 是否 $\ge 3$ yr；不满足就**否决且不递补**。
**证据**：S3、seed=42、$t=9$ yr，首选 $q_{10}(T_p)=2.323$ yr 被拒，而另一个**同价、正收益**的候选 $q_{10}=3.614$ yr 本可施工（`policy_rule_diagnostic.json`）。

**裁决**：

1. **主算不改**。理由：这是 D8 签过字的规则；中途换规则会让 E4/E5 的全部配对结果失效，44 h 内不划算。
2. **论文必须把它写成方法限制**，原话可用：
   > "The adaptive rule is a *pick-then-veto* heuristic: it ranks candidates by benefit per unit cost and then applies a minimum-protection screen to the top candidate only, without falling back to the next feasible one. This is a deliberately conservative screening rule, not an optimisation over the feasible set."
3. **允许（并建议）做一个替代规则的低成本对照**：先过滤 $T_{10}\ge3$ yr，再按减险排序，**同种子配对重跑**。若编程手能在 ≤30 min 内跑完 100 个配对种子，就作为一条 sensitivity 进附录；跑不完就只写上面那段话 + 引用 `policy_rule_diagnostic.json` 的单个案例。
4. **禁止**：把替代规则的结果当成主算；把"当前自适应表现较弱"解释成"自适应管理无效"（R2 文档已明确：弱表现可能来自行动集、预报误差与保守筛查）。

## 3. 由此产生的三条论文口径（写死）

1. **速率**：三情景的**实现**平均后退是 **1.511 / 2.628 / 3.108 m/yr**，比名义目标 1.7 / 3 / 4 低 **11 % / 12 % / 22 %**。论文里 $\rho_e$ 只能叫 "configured chronic rate"，**不得**说"模型复现了 1.7/3/4"。
2. **验证**：历史速率场留出 **$R^2=-4.30$**，必须写；结论句用 "conditional scenario tool, not a validated forecaster"。
3. **策略**：两个风险指标给出**相反排序**（S3：`repeat` 的 $E_b$ 更低、`once` 的 $E_w$ 更低），必须并列，**不得**给"唯一最优"。
