## 4. 三个最容易返工的地方（提前说）

1. **$H=h_*+B$ 的换算**：`V = H*y` 只能在**一个函数**里出现。混用 m³ 与 m³/m 是本题第一大 bug 源。
2. **单次工程固定成本 $c_0$**：如果编程手把它省掉，"一次大补 vs 多次小补"会变成无聊结论（少次永远不差）。这是 Q5 的核心，不能省。
3. **慢性损失 $L_c$ 会吃背景沙**：沙量账本必须用"有补沙 − 无补沙"的差分场算补沙去向，否则会得出"补沙的沙被侵蚀吃光了"的错误结论。

## 5. 本包**不**包含什么（明确边界）

- **没有成品代码**：按团队分工，代码由编程手实现；`modeling/sanity/erf_prototype.py` 只是 ≤150 行的参考原型（用于对拍，非成品）。
- **没有论文正文**：只有论证线、公式、图表规格。
- **没有清洗后的数据**：`data/raw/` 为空；但 `资料/` 已收录 6 份 PDF 全文 + `00_数据主表.md`（40+ 条带出处数字）；下载与清洗由编程手负责，来源清单见 `modeling/PARAM_EVIDENCE.md` §4。
- **没有"已验证"的结论**：当前所有数值都是**解析基准与量级估计**，尚未经全模型数值实验确认。论文里的结果必须来自编程手的实际运行。
